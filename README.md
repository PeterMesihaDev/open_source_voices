# open_source_voices

## voice_datasets (https://github.com/jim-schwoebel/voice_datasets)

A comprehensive list of open source voice and music datasets. I released this for the talk @ the VOICE Summit 2019.

## Common Voice (https://commonvoice.mozilla.org/en/datasets)

Common Voice is Mozilla's initiative to help teach machines how real people speak. 12GB in size; spoken text based on text from a number of public domain sources like user-submitted blog posts, old books, movies, and other public speech corpora.
